# 26. FARE ENGINE

Backend formula:

baseFare = billingKm × ratePerKm

customerTotal =
baseFare +
toll +
parking +
otherCharges

remainingBalance =
max(customerTotal - totalPaid, 0)

If totalPaid > customerTotal:

balance = 0

credit =
totalPaid - customerTotal

Use proper decimal handling.

Never use unsafe floating-point financial calculations.
