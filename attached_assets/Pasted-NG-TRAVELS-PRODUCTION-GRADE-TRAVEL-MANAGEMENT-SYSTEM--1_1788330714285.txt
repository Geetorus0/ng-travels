NG TRAVELS – PRODUCTION-GRADE TRAVEL MANAGEMENT SYSTEM
========================================================

You are a senior full-stack architect, product engineer, UI/UX designer, database engineer, security engineer and QA engineer.

Upgrade the existing NG Travels application into a REAL, PRODUCTION-READY Travel Operations Management System.

IMPORTANT:

This is NOT a UI-only project.

Do NOT create static dashboards, fake data, mock APIs, placeholder buttons, simulated calculations or frontend-only functionality.

EVERYTHING visible in the UI must be connected to a real backend/database/API and must actually work.

Before making changes:

1. Inspect the complete existing codebase.
2. Understand the current architecture.
3. Identify existing working features.
4. Preserve working functionality.
5. Fix broken functionality.
6. Remove fake/static data.
7. Implement missing backend functionality.
8. Implement proper role-based access.
9. Test every workflow end-to-end.
10. Do not break existing functionality unnecessarily.
